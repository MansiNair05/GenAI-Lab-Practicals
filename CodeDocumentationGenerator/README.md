# Student Marks Program

## Overview
The program calculates the average marks and determines the result.

## Functions
- calculate_average(marks): Returns the arithmetic mean of the marks.
- check_result(average): Returns Pass if the average is at least 40; otherwise Fail.

## Inputs
- marks: A list of numeric marks.
- average: A numeric average.

## Return Values
- calculate_average returns a number.
- check_result returns a string.

## Exceptions and Limitations
An empty marks list causes ZeroDivisionError.
Invalid input and mark ranges are not validated.

## Example Output
Marks: [75, 80, 65, 90, 70]
Average: 76.0
Result: Pass
